Due-time semantics

Review times, response targets and resolution targets are distinct. Waiting needs a reason and next review; it does not automatically pause a target.

Kanban is a team view.Use paged lists and saved filters for the full volume. Use the board for a bounded, assigned team slice; use a triage desk to work one item carefully.

Learn the work. Earn the responsibility.

Progressive disclosure of tools, backed by supervision, competence and explicit appointment.

No automatic role unlocks
01 / Participant support

Make a useful first reply.

Start with a bounded FAQ queue. Read the request, choose reviewed guidance, prepare a reply and ask a coach when anything feels uncertain.

Independent FAQ work: coach sign-off and a scoped service grant.
02 / Alert handling

Turn signals into owned work.

Learn freshness, impact, correlation, routing and escalation. Manage observations and follow-ups without confusing acknowledgment with resolution.

Supervised assessment, relevant training and current alert-triage permissions.
03 / Security duty lead

Coordinate people with clear limits.

Classify within authority, offer bounded assignments, track acceptance and coordinate a confirmed incident-command handoff when required.

Named time-valid appointment, required qualifications and explicit delegated scope.
