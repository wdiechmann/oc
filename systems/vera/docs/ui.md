# UI

The initial home page introduces VERA and labels all financial capabilities as planned. It provides no sign-in or money-moving controls yet. Header, mobile-stacked capability cards and footer adapt to narrow screens; assets are same-origin. Financial state is not fetched or inferred from EP readiness.

Start with bin/dev and open http://localhost:3001. The upcoming book UI will follow the tenant/book context, nested hierarchy, permissions and in-context update behavior in ../../finance.md and ../../system_2_plan.md.
