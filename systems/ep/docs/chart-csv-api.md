# Reviewed CoA CSV transfer (v1)

All routes are book-scoped under `/api/v1/tenants/:tenant_id/finance/books/:book_id`. Require a registered backend and current operator session. Tenant administrators may export/read setup metadata; uploads, previews and acceptance require explicit active book stewardship. Import reviews are private to the creating identity/backend, expire after one hour and are deleted by a scheduled cleanup worker. VERA parses/encodes CSV; EP validates every domain field and owns the review/atomic acceptance.

- `GET /chart-imports`: transfer information, current projected setup status, permissions, canonical columns and upload limits.
- `GET /chart-export`: one ready projected snapshot, with optional `q` number/name filter and optional matching `source_version`. Returns columns/string rows, scope, source revision and row count. No paginated accumulation/mixed snapshots. Pending/stopped/stale queries are refused.
- `POST /chart-imports`: `{headers, records}` stores a bounded private draft upload, not an accepted financial change. UTF-8 CSV is parsed by VERA into string arrays. Max 500 records, 32 columns and 2 MiB. Exact duplicate/blank headers and inconsistent row widths are rejected. No source filename is retained.
- `GET /chart-imports/:import_id`: private upload/column mapping/review, proposed creates/revisions/unchanged rows and errors.
- `POST /chart-imports/:import_id/preview`: `{mapping}` maps logical fields to uploaded header names. Type/name/position are required mappings; optional unmapped fields preserve existing values or use new-row defaults. Blank mapped fields explicitly clear optional values. Canonical scope/version columns are always checked when present. Preview validates protected current state without writing accounts/events. Re-preview replaces the digest; an old review cannot be accepted.
- `POST /chart-imports/:import_id/accept`: `{digest, expected_version}` with Idempotency-Key accepts exactly the reviewed valid plan, after current authority/expiry/owner/setup/account/reference checks. A changed chart/catalogue invalidates the review. Original receipts use `FinanceChartImport:accept` and the existing private `/me/commands` query. Receipt checks never replay mutations; identical explicit retries stay idempotent, even after draft cleanup. Another key cannot reapply an accepted review.

Canonical columns: schema_version, tenant_id, book_id, source_version, account_id, account_version, type, number, name, vat_entry_id, vat_code, category_entry_id, category_code, position, formula, active. Version is `1`. CSV preserves account numbers as strings; positions/versions use strict integers and active uses true/false. Match by stable account_id when supplied (unknown/foreign IDs are errors), otherwise by posting number in this book, otherwise create. Blank IDs for header/calculation rows create new rows. Missing source rows NEVER delete/deactivate anything. Optional supplied account versions and source revisions must be current.

Catalogue UUIDs are primary; code-only inputs resolve current entries. Supplying both must describe the same current code/entry, preventing unnoticed reassignment. Retained inactive associations may remain; new inactive/foreign/wrong-kind references fail. Validate the whole final chart, including rows not in the file: number reservations, duplicate IDs/numbers/positions, type-specific fields, formula syntax/stable references/forward references and cycles. Account numbers remain reserved after renumbering. Position swaps are accepted together under a deferred unique constraint; no partial reorder is committed. New account IDs equal their AccountCreated event IDs. Changed rows emit individual account events under one command; unchanged rows keep their revisions. Projection delivery finishes a command group atomically even at a worker page boundary. Rebuild executes no financial work.

CSV uses UTF-8 (optional BOM), comma delimiters, quoted fields and embedded quoted newlines. No numeric converters touch identifiers. Exports use a reversible apostrophe escape for text beginning with an apostrophe or spreadsheet formula trigger (`= + - @` after whitespace); import removes one defined escape. CoA formulas remain text and are never evaluated by CSV handling. CSV cannot encode spreadsheet cell types: import identifiers as Text in spreadsheet apps to preserve leading zeroes. Downloadable templates contain headers only, without example accounts that could accidentally be accepted.

Errors: 401 authentication; 404 scope/review/access; 409 version_conflict, view_pending, chart_changed, digest_conflict, invalid_review, import_already_accepted, idempotency_conflict; 410 review_expired; 422 invalid_upload/invalid_mapping; 503 view_stopped. Review row errors are returned as data and disable acceptance. Views distinguish accepted facts from projection readiness. This slice imports chart configuration only, not balances, journals, catalogue definitions or periods.
